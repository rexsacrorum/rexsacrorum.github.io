01How I ship with agents

Agents do the legwork, every step has one owner, and a person decides what ships.

  1. 1

    Research

    Agents pull the ticket, docs and code context from Jira, Confluence and GitLab over MCP.

  2. 2

    Plan

    An architecture role maps the affected components and checks the design against the code.

  3. 3

    Write

    One agent owns the source change. Never two writers on the same files.

  4. 4

    Review and verify

    A separate agent reviews the final diff; builds and Playwright tests run before anything moves on.

  5. 5

    Approve

    Nothing is pushed, merged or changed in Jira without explicit human approval. I review every change.
