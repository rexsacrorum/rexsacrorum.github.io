~/workflowHow I ship with agents

One agent keeps the plan and calls a specialist only when it pays. Every file has one writer, a fresh reviewer checks the result, and a person decides what ships.

  1. [1]

    Scope

    One task per session. A short task record carries it to the next one.

  2. [2]

    Plan

    The main agent plans and keeps the decisions. Before a risky stage it maps each requirement to a check; a hard question goes to an advisor.

  3. [3]

    Write

    Small edits stay with the main agent. Otherwise one writer per set of files, in parallel only on parts that do not overlap.

  4. [4]

    Review and verify

    An agent that has not seen the reasoning reviews the final diff. Long test runs and browser checks go to a cheaper model.

  5. [5]

    Deliver

    A request for a pull request covers the branch, commits and push. Merge, release and deploy wait for an explicit go-ahead.
